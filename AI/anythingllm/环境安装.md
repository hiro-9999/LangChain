如果想改默认模型，就改 [~/.codex/config.toml](/Users/shankou/.codex/config.toml:2) 这一行：

```toml
model = "openai/gpt-oss-20b"
```

比如默认改成 Qwen：

```toml
model = "qwen/qwen3.6-35b-a3b"
```

或者默认改成 Gemma：

```toml
model = "google/gemma-4-e4b"
```

推荐顺序：

```text
openai/gpt-oss-20b  最稳，默认推荐
qwen/qwen3.6-35b-a3b  更强但更吃资源
google/gemma-4-e4b  轻量，速度可能更好
```
